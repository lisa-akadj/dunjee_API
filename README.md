# A simple API 
This is a simple API that I have just created as a API learning exercise.
I used a list of countries as objects with the keys "name", "capitalCity" and "continet. With this API you can:
- "Get" the entire list of countries
- "Get" a country by its name
- Edit or "patch" the name, capital city or the continent of the country
- Create or "post" a new country
- "Delete" an existing country from the list. 

## How to run this API
- clone this repo 
- open this repo in your IDE
- run `npm init -y` in the terminal
- run `npm install express`
